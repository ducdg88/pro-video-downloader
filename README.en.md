## 📥 Download & Install

### Option 1: Download the .exe (recommended)

1. Go to **[Releases](../../releases/latest)**
2. Download **`Pro Video Downloader.exe`**
3. Run it. **No install needed**, it runs directly!

> ⚠️ Windows SmartScreen may warn about an "Unknown Publisher". Click **"More info"** then **"Run anyway"**.

### Option 2: Run from source (for developers)

```bash
# Clone the repo
git clone https://github.com/hoangvant77internet-sudo/pro-video-downloader.git
cd pro-video-downloader

# Install dependencies
pip install -r requirements.txt

# Run the app
python app.py
```

## ✨ Features

| Feature | Description |
|-----------|--------|
| ▶ **Download video** | Paste a link, pick a quality, download |
| ⏬ **Bulk download** | Paste many links at once and download them all |
| 📡 **Channel scan** | Scan every video of a YouTube channel/playlist and bulk download |
| 🖼 **Thumbnail download** | Download high quality thumbnails (single and bulk) |
| 🕓 **History** | Keeps download history, up to 500 videos |
| 📁 **Custom folder** | Choose where files are saved |
| 📊 **Global tracking** | Counts usage across all users (Google Sheet API) |
| 📈 **30 day chart** | Animated bar chart of the last 30 days |
| 🔄 **Auto update** | Checks for new versions on GitHub Releases |
| ☕ **Buy me a coffee QR** | Hover the coffee icon to show a bank transfer QR code |
| ⚡ **Turbo multi-thread** | 8 concurrent download threads, 15 retries, 10MB chunks |
| 🎵 **MP3 extraction** | Download audio only as MP3 (needs FFmpeg) |

## 💡 System Requirements

- **OS:** Windows 10/11 (64-bit)
- **RAM:** 4 GB or more
- **Connection:** stable Internet
- **FFmpeg** (recommended): install FFmpeg for the best quality. [Download FFmpeg](https://ffmpeg.org/download.html)

> 💡 **No FFmpeg?** The app still works, limited to pre-merged quality.
